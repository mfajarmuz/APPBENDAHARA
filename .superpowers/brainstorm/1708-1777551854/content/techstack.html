Teknologi Aplikasi Desktop

Pertanyaan 3: Pilih teknologi yang paling cocok untuk Anda

A

Electron + React

Tampilan modern berbasis web (HTML/CSS/JS). Integrasi Supabase sangat mudah. Ukuran file lebih besar (~150MB), tapi fitur lengkap dan tampilan bisa sangat rapi.

B

Tauri + React

Seperti Electron tapi jauh lebih ringan (~10MB). Tampilan modern berbasis web, integrasi Supabase mudah. Butuh Rust terinstal saat development.

C

Python + CustomTkinter

Aplikasi desktop klasik dengan Python. Lebih sederhana secara tampilan, tapi mudah di-maintain. Cocok jika Anda familiar dengan Python.

Jika tidak yakin, Electron + React adalah pilihan paling umum untuk desktop + Supabase.
